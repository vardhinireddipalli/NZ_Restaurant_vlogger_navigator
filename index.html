NZ Asian Eats — Design Notes
COMPX532 / DSIGN532 · Assignment 4 · Navigation in Visualisation
Collection
116 verified Asian restaurants across 11 NZ cities, sourced from Google Maps. Each restaurant is linked to up to 3 food vlogger visits with exact date, time, and YouTube URL — giving the collection a temporal dimension beyond a static catalogue.
Navigation techniques
Map — geographic access by city and suburb. City bubbles encode restaurant count. Gold borders mark vlogger-visited places.

City drill-down — click any city bubble to zoom into suburb level, with a heat-bar chart showing density per suburb.

Timeline — monthly bar chart of vlogger visits. Click a bar to filter by month.

7 simultaneous filters — cuisine, vlogger, city, month, price, rating, and free-text search all compose live.

Next / Previous — step through individual restaurants one at a time using the card nav buttons or ← → keyboard arrows.
Scalability
100 objectsCurrent — SVG dots, client-side JS filtering, embedded JSON. Instant, no server needed.
1,000Suburb-level cluster markers on map. Virtual scrolling in feed. Lazy-loaded JSON file. Search-as-you-type replaces full lists.
10,000Leaflet.js tile map + MarkerCluster plugin. REST API with PostGIS for spatial queries. Elasticsearch for full-text search. Server-side filter counts.
100,000+Heatmap tiles, distributed database, CDN-cached map tiles, server-side clustering.
